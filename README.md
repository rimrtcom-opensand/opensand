# opensand
CSV-driven web engine for creating story, LP, and interactive content with pure JavaScript.
CSVでストーリー・LP・体験コンテンツを作れる軽量Webエンジンです。

## 特徴
- CSVで動作
- JavaScriptのみ（サーバー不要）
- ADV / ノベル / LP / モジュールでギャラリーなど対応

## デモ
https://rimrt.com/opensand/

## 使い方
1. story.csvを用意
2. index.htmlと同じ場所に置く
3. 開くだけ

---

## ✨ Features

- Works with CSV
- Built with pure JavaScript (no server required)
- Supports:
  - Visual novels / ADV
  - Story-based content
  - Landing pages (LP)
  - Modular features such as galleries

---

## 🚀 Demo

https://rimrt.com/opensand/

---

## 🛠 How to Use

1. Prepare a `story.csv` file  
2. Place it in the same directory as `index.html`  
3. Open `index.html` in your browser  

That's it — no build, no install.

---

## 💡 Concept

OpenSand is designed to be:

- Simple (no frameworks, no build tools)
- Portable (works on any static hosting)
- Flexible (story, LP, gallery, and more)

---

## 📦 Requirements

- Modern browser (Chrome / Edge / Firefox / Safari)
